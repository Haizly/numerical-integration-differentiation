
# Numerical Integration and Differentiation (MATLAB)

## Overview
This repository contains a MATLAB-based academic project that implements and evaluates
numerical integration and differentiation methods.

The project focuses on comparing numerical approximations with analytical results
and analyzing error behavior under different parameters.

## Implemented Methods

### Numerical Integration
- Trapezoidal Rule
- Simpson’s Rule
- Monte Carlo Integration

### Numerical Differentiation
- Forward Difference
- Backward Difference
- Central Difference

## Features
- Menu-driven function selection
- Analytical vs numerical comparison
- Error calculation
- Graphical visualization of results

## Repository Structure
- `/src` – MATLAB source code
- `/report` – Final project report (PDF)
